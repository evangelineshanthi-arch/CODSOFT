# CODSOFT Task 4 - Recommendation System

## Description
A content-based recommendation system built using Python.

The system recommends books similar to the user's selected book based on genre similarity.

## Features
- Book recommendations
- Content-based filtering
- Simple and interactive console interface

## Technologies Used
- Python
- Pandas
- Scikit-learn

## Dataset
Custom dataset of books and genres stored in books.csv
